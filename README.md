# probeslug

Probe CSV/TSV slug tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/probeslug/

## Install / run

```bash
git clone https://github.com/theworker02/probeslug.git
cd probeslug
node src/cli.js
node --test
```
